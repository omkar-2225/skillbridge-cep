# SKILLBRIDGE

An intelligent skill-profiling and opportunity matching ecosystem for academia–industry collaboration: skill assessment, internships, placements, faculty programs, and institutional analytics.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Demo accounts

| Role | Email | Password |
| --- | --- | --- |
| Student | `student@skillbridge.edu` | `student123` |

Demo data lives in the browser (`localStorage`). Clear site data to reset the seed dataset.

## What is included

- Role-based portals for students, academicians, industries, and institutions
- Skill questionnaire + aptitude items, gap analysis, and role recommendations
- Internship/job matching, applications, and recruiter shortlisting
- Industry learning programs and collaboration events
- Faculty internships, FDPs, consultancy, and research calls
- Institution dashboards for readiness, demand, and placement pipeline
